序文：記録としての2010年代

2010年代は、スマートフォンが生活インフラになった10年だった。iPadとInstagramが同じ年に生まれ、AWSのクラウドが「借りる計算機」を当たり前にし、Dockerがアプリケーションの配布方法を変え、AlexNetとAlphaGoが「AIは人間の直感に勝てない」という前提を次々に覆した。前半は端末とクラウドの土台作り、後半はコンテナ標準化と深層学習の実用化が主役になる。

2010年代 前半（2010–2014年）

2010年

  • 【世界】 iPad発売（4/3）でタブレット市場が本格始動、同年にiPhone 4（6月）とInstagram（10/6）も登場し、「スマホで撮って共有する」文化の起点になった。
  • 【日本】 ソフトバンクがiPhone販売で先行する一方、国内メーカーは「ガラケー」からスマートフォンへの転換に苦しみ始めた年。
  • 【技術史】 App Store・Android Marketを通じたモバイルアプリ経済の拡大が本格化した。

2011年

  • 【世界】 IBM Watsonがクイズ番組「Jeopardy!」で人間のチャンピオンに勝利（2月）、AIが一般にも注目される契機になった。
  • 【日本】 東日本大震災（3/11）と福島第一原発事故により、Twitter・mixiなどのSNSが安否確認・情報拡散インフラとして機能した。
  • 【技術史】 クイズ番組での勝利は質問応答AIの実用性を広く示した出来事として記憶される。

2012年

  • 【世界】 Facebookが上場（5/18）。同年、AlexNetが画像認識コンテストImageNetで従来手法を大差で破り（9月）、深層学習ブームの起点になった。
  • 【日本】 LINEの利用者数が急増。震災後の安否確認需要から定着したコミュニケーションアプリとして存在感を強めた。
  • 【技術史】 GPUを用いた大規模深層学習の実用性が、画像認識という具体的な成果で初めて証明された。

2013年

  • 【世界】 Dockerが発表（3月、PyConでのライトニングトーク）され、コンテナ技術の普及が始まった。
  • 【日本】 エドワード・スノーデンによるNSA監視プログラム告発（6月）は、国内でも通信の秘密・プライバシー保護の議論を呼んだ。
  • 【技術史】 コンテナという「アプリケーションを環境ごと配布する」発想が、後のマイクロサービス化の土台を作った。

2014年

  • 【世界】 OpenSSLの深刻な脆弱性「Heartbleed」が発覚（4月）し、インターネット全体の暗号化基盤の脆弱さが露呈した。
  • 【日本】 LINEが利用者数の世界5億人突破を発表、国内発アプリの国際展開の象徴になった。
  • 【技術史】 Dockerの普及が本格化し、コンテナ化・マイクロサービス化が業界標準の潮流になり始めた。

2010年代 後半（2015–2019年）

2015年

  • 【世界】 GoogleがTensorFlowをオープンソース公開（11/9）、機械学習フレームワークの民主化が進んだ。
  • 【日本】 マイナンバー制度の通知が開始（10月）、国内行政のデジタル化議論が本格化した。
  • 【技術史】 Kubernetes 1.0がリリース（7/21）、コンテナオーケストレーションの標準化競争が始まった。

2016年

  • 【世界】 DeepMindのAlphaGoが囲碁の世界トップ棋士イ・セドルに4勝1敗で勝利（3/9〜15、ソウル）、AIが人間の直感的ゲームでも優位を示した。
  • 【日本】 熊本地震（4月）でもクラウドサービス・SNSが被災地の情報共有基盤として機能した。
  • 【技術史】 ポケモンGO配信（7月）がAR（拡張現実）とスマホゲームの融合を世界的ブームにした。

2017年

  • 【世界】 ランサムウェア「WannaCry」が世界150カ国以上に拡散（5月）、サイバーセキュリティの脆弱性を露呈した。Appleが顔認証「Face ID」搭載のiPhone Xを発表（9月）。
  • 【日本】 改正資金決済法が施行され仮想通貨交換業者登録制度が開始（4月）、ビットコイン取引が一般層にも広がった。
  • 【技術史】 Transformerアーキテクチャを提案した論文「Attention Is All You Need」が発表（6月）され、後の大規模言語モデルの基盤になった。

2018年

  • 【世界】 EU一般データ保護規則（GDPR）が施行（5/25）。Facebook-Cambridge Analyticaスキャンダルが発覚（3月）し、個人データの扱いが世界的関心事になった。
  • 【日本】 仮想通貨交換業者コインチェックからNEM（ネム）約580億円相当が流出（1月）、国内仮想通貨規制強化の契機になった。
  • 【技術史】 データプライバシー規制が世界標準になる転換点となった年。

2019年

  • 【世界】 5G商用サービスが韓国・米国などで開始した。
  • 【日本】 キャッシュレス決済還元事業が開始（10月、消費税率引き上げと同時）、PayPay・LINE Payなどスマホ決済の競争が加速した。
  • 【技術史】 OpenAIがGPT-2を発表（2月）、大規模言語モデルへの関心が高まり始めた。

IT史ウィンドウ（2010年代・一行まとめ）

  • 2010年：iPad・Instagram登場でスマホ中心の情報発信が始まった。
  • 2011年：震災がSNSの社会インフラとしての価値を証明した。
  • 2012年：AlexNetの勝利が深層学習ブームの起点になった。
  • 2013年：Dockerの登場がコンテナ時代の幕を開けた。
  • 2014年：Heartbleedが暗号化基盤の脆弱さを可視化した。
  • 2015年：TensorFlowとKubernetesが機械学習・コンテナの標準を作った。
  • 2016年：AlphaGoの勝利がAIの到達点を塗り替えた。
  • 2017年：WannaCryとTransformerが脅威と技術革新を同時に示した。
  • 2018年：GDPRがデータプライバシーを世界標準に押し上げた。
  • 2019年：5G商用化が次の10年の通信基盤を準備した。

結論

2010年代は「個人が持つ端末」と「データセンターの集中」が同時進行した10年だった。iPadとInstagramで始まり、AWSのクラウドとDocker・Kubernetesがその裏側を支え、AlexNetとAlphaGoが「AIにできること」の認識を塗り替えた。一方でHeartbleed・WannaCry・GDPRが示すように、便利さの裏でセキュリティとプライバシーの課題が積み上がった10年でもあった。この緊張関係が、次の10年（生成AIの時代）のテーマを準備した。
