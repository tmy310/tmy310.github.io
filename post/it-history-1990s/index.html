序文：記録としての1990年代

1990年代は、研究者の道具だったコンピュータとネットワークが、10年かけて一般家庭のリビングまで届いた時代だった。前半はTim Berners-LeeのWorld Wide Web発明とWindowsのGUI覇権確立が静かに進み、後半はMosaic・Netscapeによるブラウザ戦争、Windows 95フィーバー、そしてGoogle・Napsterの登場でインターネットが一気に大衆化した。日本ではパソコン通信（NIFTY-Serve・PC-VAN）からインターネットへの移行、PHS、そしてiモードという独自のモバイルインターネット文化が同時進行した10年でもある。

1990年代 前半（1990–1994年）

1990年

  • 【世界】 Microsoftが「Windows 3.0」を発売（5/22、ニューヨークでの発表会）。GUIの実用性を大きく引き上げ、年末までに出荷100万本を突破した。
  • 【世界】 Tim Berners-LeeがCERNでWWWの要素技術（HTML・HTTP・URL）の開発に着手し、NeXTマシン上で世界初のWebサイトを稼働開始（12/20。alt.hypertextニュースグループでの一般告知は翌1991年8月6日）。
  • 【日本】 日本では資産バブルが崩壊し始める一方、NIFTY-ServeやPC-VANといったパソコン通信が個人利用者層を広げていた。

1991年

  • 【世界】 Linus Torvaldsが「comp.os.minix」上でLinuxカーネルの開発を公表（8/25）。趣味のプロジェクトとして始まったOSが、後のサーバー・クラウド基盤の中核になる。
  • 【世界】 Tim Berners-LeeがCERN内のニュースグループでWWWプロジェクトを広く告知（8/6）、インターネット外部への公開が始まった。
  • 【日本】 Windows 3.0の日本語版が発売され、国内PCメーカー各社がDOS/V互換機への対応を本格化させた。

1992年

  • 【世界】 Microsoftが「Windows 3.1」を発売（4月）。マルチメディア拡張やTrueTypeフォント対応で、Windows 3.0からの実利用層を拡大した。
  • 【世界】 インターネット・ソサエティ（ISOC）が設立され、学術網から商用網へのインターネット開放議論が進んだ。
  • 【日本】 NIFTY-Serve・PC-VANの会員数が拡大を続け、パソコン通信が国内オンラインコミュニティの中心であり続けた。

1993年

  • 【世界】 NCSA MosaicブラウザがUnix版として公開（1/23）、同年秋にWindows・Mac版も登場し、画像をインラインで表示できるWebブラウザが一般利用者の手に届いた。
  • 【日本】 商用インターネット接続サービスが国内でも立ち上がり始め、大学・研究機関中心だったネットワークが企業利用に広がる端緒となった。

1994年

  • 【世界】 ホワイトハウスが公式サイト「Welcome to the White House」を開設（10/20）するなど、政府機関のWeb活用も始まった。
  • 【世界】 Netscape Communications（当時Mosaic Communications）が設立され、Netscape Navigatorの開発が始動。Jeff BezosがAmazon.com（当初社名Cadabra）を創業（7/5、ワシントン州ベルビューのガレージで）。
  • 【世界】 Marc AndreessenらMosaic開発チームの主要メンバーがNetscapeに合流し、ブラウザ戦争の火種が生まれた。
  • 【日本】 IIJ（インターネットイニシアティブ）をはじめとする国内プロバイダが商用インターネット接続サービスを本格展開し、パソコン通信からインターネットへの移行が始まった。

1990年代 後半（1995–1999年）

1995年

  • 【世界】 Microsoftが「Windows 95」を発売（8/24）、発売4日間で100万本超を販売する社会現象となった。Sun MicrosystemsがJavaを発表（5/23、「Write Once, Run Anywhere」。正式版JDK 1.0のリリースは1996年1月）。Pierre Omidyarが後のeBayとなるオークションサイトを創業（9/3）。
  • 【日本】 日本語版Windows 95が発売（11/23、勤労感謝の日）、深夜販売に秋葉原で2万人超が詰めかける熱狂を見せ、PCが「マニアの道具」から「家庭の道具」へ変わる転換点になった。
  • 【技術史】 阪神・淡路大震災（1月）を機に、安否確認手段としてのインターネット・パソコン通信の有用性が国内で再認識された。

1996年

  • 【世界】 Sabeer BhatiaとJack SmithがHotmailを開始（7/4）、Webブラウザだけで使える無料メールという概念を広めた。U.S. Robotics傘下のPalm ComputingがPalmPilotを発売（3月。3Comによる親会社U.S. Robotics買収は翌1997年6月）、PDA市場を立ち上げた。
  • 【日本】 米Yahoo!とソフトバンクの合弁でヤフー株式会社が設立（1/31）、国内初の商用検索サイトYahoo! JAPANがサービスを開始（4/1）。
  • 【技術史】 ブラウザ戦争が激化し、NetscapeとMicrosoft Internet Explorer 3.0が機能競争を繰り広げた。

1997年

  • 【世界】 IEEE 802.11が最初の無線LAN標準として策定（6月）、後のWi-Fiの技術基盤になった。検索エンジン市場ではAltaVista・Yahoo!・Excite・Lycosが競合し、Googleはまだ創業前だった。
  • 【日本】 山一證券が自主廃業を発表（11月）、金融システム不安の中で証券取引の電子化・ネット証券への関心が高まった。
  • 【技術史】 DVDが日本・米国で発売され、CDに続く光ディスク規格の世代交代が始まった。

1998年

  • 【世界】 Larry PageとSergey Brinがスタンフォード大学院生としてGoogleを創業（9月、メンローパークのガレージで）。AppleがボンダイブルーのiMacを発売（米国8/15、日本8/29）、Jobs復帰後のApple再生を象徴する製品となった。
  • 【日本】 NTTドコモの携帯電話契約数が急拡大し、ポケベルからの利用者移行が本格化した。
  • 【技術史】 Microsoft独占禁止法訴訟が米司法省により提起され（5月）、ブラウザ抱き合わせ販売が争点になった。

1999年

  • 【世界】 Shawn FanningがP2P音楽共有サービスNapsterを公開（6/1）、著作権とデジタル配信をめぐる論争の起点になった。世界中の企業・政府がY2K問題（2000年問題）対応に追われ、システム総点検が行われた。
  • 【日本】 NTTドコモが携帯電話からインターネットに接続できる「iモード」を開始（2/22、世界初のモバイルインターネットサービス）。契約数は翌年8月に1,000万人を突破した。
  • 【技術史】 IEEE 802.11準拠製品に「Wi-Fi」のブランド名が与えられ（Wi-Fi Alliance発足）、無線LANの普及が始まった。

IT史ウィンドウ（1990年代・一行まとめ）

  • 1990年：Windows 3.0とTim Berners-LeeのWWW開発着手が、GUIとネットワークという2本柱を同時に動かし始めた。
  • 1991年：LinuxカーネルとWWWの外部公開が、趣味プロジェクトから後の基盤技術への出発点になった。
  • 1992年：Windows 3.1がGUIの実利用を広げ、国内はパソコン通信全盛期を迎えていた。
  • 1993年：Mosaicブラウザの登場が、画像入りWebページを一般利用者に開放した。
  • 1994年：Netscape設立とAmazon創業が、ブラウザ戦争とEコマースという2つの潮流の起点になった。
  • 1995年：Windows 95フィーバーが、PCを「家庭の道具」へ変えた象徴的な年。
  • 1996年：HotmailとPalmPilot、日本ではYahoo! JAPANが、常時接続前夜の利便性を形作った。
  • 1997年：Wi-Fiの標準策定が進む一方、日本は山一證券破綻で金融システムの電子化に直面した。
  • 1998年：GoogleとiMacが同じ年に生まれ、検索とデザインという2つの革新の種がまかれた。
  • 1999年：NapsterとY2K対応が、デジタル配信への期待と既存システムへの不安を同時に示した。

結論

1990年代は「ネットワークとGUIが大衆の手に渡った」10年だった。前半はWindows 3.0とTim Berners-LeeのWWW発明という静かな技術的土台作りの時期であり、後半はMosaic・Netscapeによるブラウザ戦争とWindows 95フィーバーが一気に加速させた。そしてGoogle創業とNapster登場という1990年代最後の2年が、検索とデジタル配信という2000年代を規定する潮流の原点になっている。日本ではパソコン通信からインターネットへの移行、そして世界に先駆けたiモードが、独自のモバイルインターネット文化の出発点になった。
